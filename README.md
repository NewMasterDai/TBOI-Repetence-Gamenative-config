# TBOI Repentance Config

A configuration profile enabling DLC functionality for The Binding of Isaac.

## Requirements
Requires download a specific Turnip driver
https://github.com/MrPurple666/purple-turnip/releases

## Installation
- Add the Turnip driver inside of Gamenative's driver manager.
- Download TBOI with all DLC's.
- Under the game's settings, import this config
